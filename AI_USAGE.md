# AI Usage Statement

During the development of this project, AI assistants were used strictly in the following capacities:

1. **Code Scaffolding**: To generate boilerplate code for FastAPI endpoints, Streamlit layouts, and Pydantic models.
2. **Infrastructure Generation**: AI tools assisted in drafting the multi-stage Dockerfile, Jenkins pipeline logic, and Terraform configurations, which were then thoroughly audited and refined to match exact project requirements.
3. **Debugging and Syntax**: Assistance was sought for resolving strict JSON Pydantic parsing issues and HTTP timeout configurations.
4. **Mock Provider Strategy**: AI was engaged to brainstorm keyword mappings and edge cases for the deterministic MockProvider to ensure stable CI performance.

All outputs were vetted, tested, and modified manually to meet the assignment specifications.
